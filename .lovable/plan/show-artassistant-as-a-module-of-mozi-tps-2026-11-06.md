- **ARTAssistant page:**
  - Add a "Part of: MOZI TPS (Module)" link to the MOZI page.

  - Remove the limitation saying it isn't confirmed to be the same software. Instead, the source will note that the user confirmed on 2026-11-06 that it is a MOZI module, alongside the ESTRO 2026 abstract.

- **Manteia company page:** ARTAssistant stays in the product list.
- **Report:** the row is changed to "module of MOZI TPS" in a new version (v3) in Files.
